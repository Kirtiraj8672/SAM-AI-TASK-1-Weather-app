# 🌦️ Weather App

A responsive Weather Application built using **HTML, CSS, and JavaScript**. The app allows users to search for any city and view real-time weather information using a public weather API.

## 🚀 Features

- Search weather by city name
- Displays:
  - Temperature
  - Weather condition
  - Humidity
  - Wind Speed
- Responsive design for desktop and mobile
- Error handling for invalid city names
- Clean and user-friendly interface

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- Weather API
