# 🌦️ Weather App

A modern, responsive Weather Application built using **HTML**, **CSS**, and **JavaScript**. The application allows users to search for any city and view real-time weather information using a public weather API.

---

# 📖 Overview

The Weather App is designed to provide users with accurate and real-time weather information through a clean and intuitive interface. Users simply enter a city name to view its current weather details, including temperature, humidity, wind speed, and weather conditions.

This project was developed as part of my **Web Development Internship at SAM AI Technologies** to improve my frontend development skills and understanding of API integration.

---

# ✨ Features

- 🌍 Search weather by city name
- 🌡️ Real-time temperature display
- 💧 Humidity information
- 🌬️ Wind speed display
- ☁️ Weather description and icon
- ❌ Handles invalid city names gracefully
- 📱 Responsive design for all devices
- ⚡ Fast and lightweight user interface
- 🎨 Clean and modern design

# ⚙️ How It Works

1. User enters a city name.
2. JavaScript sends a request to the Weather API.
3. The API returns weather information.
4. The application displays:
   - City Name
   - Temperature
   - Weather Condition
   - Humidity
   - Wind Speed
5. If the city is invalid, an appropriate error message is displayed.
